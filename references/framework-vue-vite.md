# Vue and Vite integration

Call `startMeisheSdkForProjectLoad()` from the editor route/project loader's `onMounted()` hook as soon as runtime and authorization configuration are available, and retain its singleton promise. After the loading canvas mounts, call `loadEditorProject()` in the same project-loading lifecycle so Timeline creation/loading, LiveWindow creation/connection, graph restoration, and any non-empty initial seek complete before project readiness. Guard an in-flight load with the component generation; dispose a session that resolves after unmount or supersession. Do not create that foundation from file selection, upload, editing click, drag/drop, or play. Store opaque SDK objects in ordinary variables or `shallowRef`; avoid deep reactive proxies. Start the idempotent asynchronous editor-session `dispose()` from `onBeforeUnmount()` and route any rejected cleanup promise to project error reporting. SDK startup remains editor-application-owned across temporary component remounts.

Keep loader and session code framework-neutral. A composable may expose readiness, errors, and commands, but should not hide missing SDK/WASM, authorization, or package dependencies. Do not recreate a timeline from a watcher unless the user explicitly requests a new project.

Vite considerations match the React guide: use a customer-provided static/remote SDK root, keep browser globals out of SSR evaluation, and verify MIME/CORS/cross-origin headers for the chosen build. The bundled `references/NvStreamingSdk.js` must not enter `public/`, an import graph, or a deployment artifact.

Start from [sdk-startup.ts](../assets/samples/core/sdk-startup.ts), select an empty/application-XML/SDK-native branch with [project-loading.ts](../assets/samples/core/project-loading.ts), and pass it to [editor-bootstrap.ts](../assets/samples/core/editor-bootstrap.ts); use [sdk-loader.ts](../assets/samples/core/sdk-loader.ts) and [editor-session.ts](../assets/samples/core/editor-session.ts) separately only for an existing partial integration. Validate initialization before project readiness, mount, preview, seek/play, awaited unmount cleanup, and a second mount. Confirm callbacks are not duplicated and the old LiveWindow/timeline are removed.
