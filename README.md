# meishe-streaming-sdk-web-skills

> Modular Web AV skills for capture, editing, effects, recording, and streaming-ready output.

## Overview

Meishe Streaming SDK Web Skills packages production-grade audio/video capabilities into composable modules for browser-based applications. Teams can integrate only the skills they need and build live streaming, video creation, and real-time AV experiences faster—without building a complete streaming pipeline from scratch.

## Key Skills

- **Capture & Preview** — browser camera/microphone input and real-time preview
- **Real-time AV Processing** — audio/video processing for interactive web scenarios
- **Timeline Editing** — timeline, tracks, clips, and trimming for web editing workflows
- **Effects & Packaging** — filters, overlays, and visual packaging
- **Recording & Output** — recording, export, and streaming-ready pipelines

## Why These Skills

- Composable modules for lean Web integration
- Production-grade streaming and AV architecture
- Designed for browser-based video and live apps
- Faster time-to-market for streaming and creation features

## Typical Use Cases

Live streaming · video creation tools · social web apps · online education · enterprise media · e-commerce live experiences

1. Review the integration guide and Web sample project.
